# Final adapters

This directory contains the two adapters used by the final solution:

- `old_bad/` — OLD BAD adapter from the preserved best-runtime lineage.
- `new_fire/` — successful NEW FIRE adapter used in Hybrid A and the private-best run.

The `.safetensors` files are tracked with Git LFS in `.gitattributes`. Exact SHA256 values are recorded in `manifests/final_artifacts.json`.
